How to use this tool

01

Convert PDF using Gemini

Open gemini.google.com, paste the full extraction prompt (shared in team group), fill in the Paper Details section, attach the exam PDF and hit send.

02

Save output as JSON

Copy Gemini's response. Open VS Code, create a new file, paste the JSON, save with format: class{X}_{subject}_{year}_set{N}.json

03

Verify here

Click "Open Checker" below, enter your team access key, then upload the JSON file. The tool renders the full paper UI automatically.

04

Cross-check with original PDF

Compare the rendered UI with the original exam PDF. Verify all questions, options, marks, and section labels are correct. A red error means do not upload yet.

05

Upload verified JSON to Drive

Once confirmed correct, upload the JSON to your assigned Google Drive folder. Upload only verified files — no exceptions.

File naming convention

Save your JSON using this exact format. Deviating from the pattern will cause upload rejection.

class{X}_{subject}_{year}_set{N}.json
class10_science_2024_set1.json class12_maths_2025_set3.json class10_hindi_a_2026_set5.json class12_biology_2024_set2.json
